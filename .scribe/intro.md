# Introduction

API documentation for the Equipment Maintenance Tracking System.

<aside>
    <strong>Base URL</strong>: <code>http://localhost:8000</code>
</aside>

This documentation provides information about the Equipment Maintenance Tracking System API.

You can explore the available endpoints, view request and response examples, and test API requests using the documentation interface.

Protected endpoints require a valid JWT Bearer Token obtained through the login endpoint.
